# Legacy paths (archived, not maintained)

This directory contains code and hardware notes that are no longer part of the
active BF_Anti runtime. They are kept for reference, rollback, and historical
reproduction. New work must use the Pi5 mainline in onboard/ and docs/sim2real/.

- rdk_x5_pico/ - RDK X5 companion, Pico SPI/CVBS video, local CRSF/MSP RC path.
